## How to use this template

1. **At publish time** for each video: fill the artifact pass/fail row for that video. Don't wait for the cycle to end — recall is fresher right after shipping.
2. **At the end of the cycle** (after all videos in the batch are published, before starting the next batch's SOP 01): fill sections 2-6.
3. **Update SOPs** per section 3, then commit the SOP changes BEFORE starting the next cycle's SOP 01. This is the "refine before next cycle" gate.
4. **Don't skip section 5.** It's the only section that can kill the project. Always answer honestly.
