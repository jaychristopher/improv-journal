# SOP 05 · Critique Round 1 — Retention KPIs

**Lens:** algorithm-facing. Score what YouTube's ranking signals reward (CTR proxies, AVD proxies, structural hooks). This is the "does the script tick the boxes the algorithm watches?" pass.

**This SOP is NOT:** a taste pass. Don't ask "does the bridge feel earned?" here — that's SOP 06.

## Purpose

Score the v1 script against the 30 engagement rules. Identify the 3-5 highest-ROI fixes for v2. This is a checklist pass, not a creative pass.

## Inputs

- Script v1 from SOP 04
- The 30 engagement rules — canonical reference: [`REFERENCE-engagement-rules.md`](./REFERENCE-engagement-rules.md)

## Outputs

A scoring section in the buildup doc with:
- Per-rule score (1-5) for the 13 script-relevant rules
- Total score and percentage
- 3-5 highest-ROI v2 edits identified
- "What works — don't touch" surfaces preserved

## Tools

- Read the script
- Manual scoring with the rubric below

## Rubric (13 script-relevant rules)

Skip visual-only rules (20-25); they apply at the Remotion stage.

| # | Rule | What "5/5" looks like |
|---|------|----------------------|
| 1 | Hook in 3 seconds | First sentence is a counterintuitive claim or specific stake; ≤ 8 spoken words |
| 2 | Payoff before earned | The reframe / answer lands inside first 15 seconds |
| 5 | Stakes in 15s | Explicit cost named, not implied |
| 8 | Re-hook every 30-60s | Visible cadence change every minute or less |
| 14 | Open loops | Specific thing promised in first 30s, resolved later |
| 15 | Midpoint reveal | Most quotable line lands at ~50%, isolated by pauses |
| 16 | 3-act structure | Hook → mechanism+moves → antipattern+close, all present |
| 17 | CTA after value | URL only at end |
| 18 | Specificity | Named teachers + years + numbers + 2-3 worked examples |
| 19 | End on callback | Last line echoes opening hook |
| 26 | Conversational | Second-person "you", contractions, no academic register |
| 27 | Dynamic range | Multiple [emote] tags varied across beats |
| 29 | One question | Title's question is answered exactly once |

## Steps

1. **Read the v1 aloud.** Note: any line that feels flat, any pause that runs long, any place where you'd skip ahead.
2. **Score each of the 13 rules** on a 1-5 scale. Be honest. Most v1 scripts will score 50-55/65 (B/B+). That's normal — the point of v2 is to push it to A.
3. **Identify the lowest 3-5 scores.** These are the highest-ROI v2 edits.
4. **For each low score, write a specific fix.** Not "improve hook" — instead "Cut 'If you want to be funny' from line 1; opening becomes 'Stop trying.'"
5. **Identify what's working.** Anything scoring 5/5 is sacred — don't let v2 break it. Write a "DON'T TOUCH" surfaces list.
6. **Write the audit section** of the buildup doc with: rubric table, total, top 5 fixes, don't-touch list.
7. **Project the v2 score.** State the projected percentage if the top 5 fixes are applied. Helps you know if v2 is enough or needs another pass.

## Quality bar

- All 13 rules scored
- 3-5 specific v2 edits identified, each as a concrete instruction not abstract advice
- "Don't touch" surfaces named (≥ 3)
- Projected v2 score named

## Common pitfalls

- **Scoring too kindly.** v1 scripts almost always have stakes = 3 and open loops = 2. Be honest; the score is for you, not for show.
- **Edits stated abstractly.** "Strengthen the hook" is useless. "Replace 'If you want to be funny, stop trying to be funny' with 'Stop trying to be funny' to cut filler" is actionable.
- **Ignoring the don't-touch list.** v2 sometimes destroys what worked in v1. Naming the sacred surfaces protects them.

## Lessons from prior production

- L2 v1 scored 53/65 (82% B+). Lowest scores: stakes (3), open loops (2), midpoint (3). v2 hit projected 60/65 (92% A) by fixing all three.
- "Hook in 3s" was 5/5 across all 4 v1 scripts — but only after retraining out the "If you want to..." filler. Watch for it.
- Specificity was 5/5 across all 4 v1 scripts — direct citations from the bridge made this easy.
