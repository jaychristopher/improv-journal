# SA-17.1 — Settle who owns Viewpoints

## What was found

`content/bridges/viewpoints.md` declares six target keywords, `serp_checked:
2026-08-23`, `serp_min_dr: 6`, `serp_verdict: winnable`. It is promoted from all
386 pages.

Search Console, `gsc-keywords`, 2026-02-01 → 2026-09-25. Every Viewpoints query
the site has ever surfaced for, and the page Google chose:

**Fifteen queries, ~35 impressions, and `/viewpoints` takes none of them.** Four
of the six keywords the guide was written to win are being served by the book's
citation page.

The titles say why:

- guide — `Anne Bogart Viewpoints: The Nine Channels`
- citation — `The Viewpoints Book — Anne Bogart & Tina Landau (2005)`

Both lead with the same entity, and Google picked the citation.

**And the collision test could not have caught it.** CLAUDE.md names `parent` as
the test — "two pages competing is not detectable from distinct keyword strings,
it is detectable from a shared parent topic". The guide declares `parent:
"viewpoints"` on four keywords. The citation is an atom, so per SA-5.1 it has no
`parent`, no keywords and no verdict. There is nothing on the other side of the
comparison.

**It is not a one-off.** `ref-spolin-improvisation-for-theater` takes six
queries — "viola spolin improvisation for the theatre", "improvisation for the
theatre", and variants — while the `/viola-spolin` guide takes none. SA-11.1
found a third page about Spolin at `/traditions/spolin`.

## What this is not

It is not an argument that the citation should be demoted. Several of these
queries are genuinely about the book — "anne bogart viewpoints pdf", "the
viewpoints book" — and the citation is the right answer for those. The defect is
that one page is answering both intents and nothing decided that it should.

Nor is it a reason to merge or redirect. Both pages have a job.

## Run

1. **Split the fifteen queries by intent.** Book-intent — the pdf query, "the
   viewpoints", queries naming the authors — belongs to the citation.
   Concept-intent — "viewpoints acting", "viewpoints acting exercises",
   "viewpoints technique" — belongs to the guide. Write the split down; it is
   the decision the rest depends on.
2. **Retitle on that split, not on instinct.** The guide's title leads with
   "Anne Bogart Viewpoints", which is the citation's territory. If the guide is
   to own the craft queries its title should lead with the craft, and the
   citation's should lead with the book. Check the alias guard after, and watch
   position as the control the way SA-1.1 does — the citation currently sits at
   53–72 and a careless swap could cost both.
3. **Give the citation a `parent`.** This is the smallest durable fix: a
   `parent` on the reference atom is what would let the collision test run next
   time. It depends on SA-5.1's placement decision; if that has not landed,
   record the parent in the card and note the dependency rather than inventing
   a location.
4. **Check the whole library against the guides.** Spolin is confirmed. Do the
   same comparison for every reference atom whose subject also has a guide —
   `del-close`, `theatre-games`, `yes-and-improv`, `what-is-improv` — and report
   the count. That number is the size of this problem and nobody has it.
5. **Do not merge, redirect or unpublish anything.** Both pages earn their
   place, and SA-7.1 is still watching one URL migration land.

## Verify

- The fifteen queries are recorded with an owner each.
- Both pages' titles and descriptions reflect that split.
- The reference atom carries a `parent`, or the dependency on SA-5.1 is written
  down.
- The count of guide/citation subject overlaps across the library is reported.
- No page was merged, redirected or removed.
- `npm run check` green; re-read positions for both pages after 30 days, reading
  from 2026-02-01 per SA-16.1.
