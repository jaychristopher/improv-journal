# SA-2 — An unreadable profile

At DR 0.2 the binding constraint on everything else in this epic is that no
page has the authority to rank for anything contested. Internal linking
redistributes; it does not create.

Which makes the referring-domain profile the most important number on the site,
and it is currently unreadable: it grows every month whether or not anybody has
done anything, so the one activity that would actually move the constraint —
earning a real citation — cannot be told apart from noise.

This story is about making that number mean something, not about chasing links.
